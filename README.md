# Rayyan's Portfolio

A personal portfolio showcasing my work across AI/ML, local language models,
full-stack engineering, and research.

## Highlights

- Professional software engineering and machine learning experience
- Privacy-focused EEG research
- Local-LLM and on-device AI projects
- Full-stack project demos and source code
- Interactive particle background and randomized cat surprise
- A Beyond Code section for music and fitness

## Built With

- [Astro](https://astro.build/)
- [Tailwind CSS](https://tailwindcss.com/)
- TypeScript and browser-native JavaScript

## Run Locally

```bash
npm install
npm run dev
```

Then open [http://localhost:4321](http://localhost:4321).

Create a production build with:

```bash
npm run build
```
